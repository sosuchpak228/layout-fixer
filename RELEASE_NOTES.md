Экспериментальное обновление Layout Fixer для Windows 10/11 x64. Выделите текст, набранный в неверной раскладке, и нажмите **Ctrl+Alt+L**. Программа сохраняет регистр и не использует буфер обмена.

### Что изменилось

- Помимо обычного `Edit`, программа пробует редактируемые элементы браузера, которые Windows показывает как другой тип, но которые поддерживают `TextPattern` вместе с редактируемым `ValuePattern` или `TextEditPattern`.
- Перед заменой повторно проверяются активное окно, элемент в фокусе и выделенный текст.
- Для сложных редакторов добавлен `--diagnostics`: он показывает только технические признаки активного элемента и причину пропуска, без самого текста.

Это **preview**, а не подтверждённое исправление для каждого сайта: поиск Яндекса и ноды Magnific Canvas Space нужно проверить на реальных рабочих местах. Для проверки рядом с установленной версией запустите `layout-fixer.exe --test-hotkey` и используйте **Ctrl+Alt+F12**. Тот же x64 EXE рассчитан на Windows 10 и 11; реальный тест на Windows 11 пока ожидается.

### Скачать и проверить

1. Скачайте ниже **`layout-fixer.exe`** и запустите без прав администратора. ZIP необязателен.
2. Выделите тестовый текст в нужном приложении и нажмите выбранное сочетание. Для своего сочетания используйте, например, `--hotkey Ctrl+Alt+A`.
3. Если конвертация пропущена, запустите тестовую копию с `--test-hotkey --diagnostics`; инструкция по сохранению диагностических строк есть в [README](https://github.com/sosuchpak228/layout-fixer#readme-ov-file).

Автозапуск включается только вручную через ярлык в `shell:startup`. Для удаления выйдите через значок в трее, удалите ярлык и EXE. Программа не устанавливает службу или драйвер. Код распространяется по лицензии MIT, но EXE пока **не подписан цифровой подписью**. Сверяйте источник и SHA-256; подпись издателя потребует отдельного сертификата и не гарантирует отсутствия предупреждения SmartScreen.

**Файлы:** EXE — готовая программа; `layout-fixer-windows-x64.zip` — EXE, README и лицензия; `SHA256SUMS.txt` — контрольные суммы. Архивы **Source code** GitHub создаёт автоматически. Исходники можно смотреть во вкладке [Code](https://github.com/sosuchpak228/layout-fixer), точную версию — по тегу релиза.
