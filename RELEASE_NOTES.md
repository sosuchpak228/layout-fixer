Небольшая переносимая утилита для Windows x64: выделите текст, набранный в неверной раскладке, и нажмите **Ctrl+Alt+L**. Работает в обе стороны (EN/RU), сохраняет регистр и не использует буфер обмена.

### Установка и использование

1. Скачайте ниже **`layout-fixer.exe`** и поместите его в удобную постоянную папку. ZIP не обязателен.
2. Запустите EXE без прав администратора. Значок появится в области уведомлений.
3. Выделите текст в редакторе и нажмите **Ctrl+Alt+L**. Если сочетание уже занято другой программой, запустите EXE с `--test-hotkey` и проверьте **Ctrl+Alt+F12**.

Автозапуск включается только вручную: поместите ярлык на EXE в `shell:startup`, предварительно отключив другой слушатель того же сочетания. Для удаления выйдите через значок, удалите ярлык и EXE. Программа не устанавливает службу или драйвер. Она пока не подписана цифровой подписью; перед запуском сверяйте источник и SHA-256.

**Файлы:** EXE — готовая программа; `layout-fixer-windows-x64.zip` — EXE, README и лицензия; `SHA256SUMS.txt` — контрольные суммы. Архивы **Source code** GitHub создаёт автоматически. Исходники можно смотреть прямо во вкладке [Code](https://github.com/sosuchpak228/layout-fixer), а точную версию — по тегу этого релиза.
