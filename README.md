# Layout Fixer

[English](README.en.md)

[![Скачать для Windows x64](https://img.shields.io/badge/Download-Windows%20x64-0078D4?logo=windows)](https://github.com/sosuchpak228/layout-fixer/releases/download/v0.1.0-preview.6/layout-fixer.exe)

Небольшая утилита для Windows, которая исправляет текст, набранный в неверной русской или английской раскладке. Выделите текст и нажмите **Ctrl+Alt+L**: `ghbdtn` станет `привет`, а `руддщ` — `hello`. Регистр сохраняется: `Ghbdtn` → `Привет`, `HF,JNFTN` → `РАБОТАЕТ`.

Программа **не копирует выделенный текст в буфер обмена**, не добавляет его в историю Win+V и ничего не отправляет в сеть. Она читает выделение через Windows UI Automation или обычное поле Win32 `Edit` и заменяет его вводом Unicode. Если редактор не поддерживает такой способ чтения, текст останется без изменений.

Версия `preview.6` сохраняет экспериментальную поддержку редактируемых браузерных полей, которые Windows описывает не как `Edit`, а через доступные `ValuePattern` или `TextEditPattern` вместе с `TextPattern`. Это не гарантия для каждого сайта. Один и тот же EXE рассчитан на Windows 10 и 11 x64; проверка на реальной Windows 11 пока нужна.

## Скачать и запустить

1. Для portable-проверки скачайте `layout-fixer.exe` из [последнего preview-релиза](https://github.com/sosuchpak228/layout-fixer/releases) и запустите без прав администратора.
2. Для полноценной установки скачайте ZIP, распакуйте его и запустите `install.cmd`. Утилита скопируется в `%LOCALAPPDATA%\Programs\LayoutFixer`, добавит автозапуск текущего пользователя и появится в списке установленных приложений Windows.
3. Значок появится в области уведомлений Windows. Выделите текст в редактируемом поле и нажмите **Ctrl+Alt+L**. В меню значка доступны **Exit Layout Fixer** и **Uninstall Layout Fixer**; удалить программу также можно через **Параметры → Приложения → Установленные приложения**.

Portable-режим не меняет автозапуск и реестр. Установочный режим использует только профиль текущего пользователя, не требует администратора, службы или драйвера. Удаление убирает EXE, ярлык автозапуска и запись приложения, но не трогает другие файлы пользователя. Исходники распространяются по лицензии [MIT](LICENSE), но лицензия не является цифровой подписью. EXE пока не подписан сертификатом издателя, поэтому Windows может показать предупреждение SmartScreen. Даже подпись не гарантирует мгновенной репутации. Перед запуском проверьте адрес репозитория и при необходимости сравните SHA-256 с файлом `SHA256SUMS.txt` на странице релиза.

### Если Ctrl+Alt+L уже занят

Не запускайте два слушателя на одном сочетании. Для проверки рядом с существующей утилитой запустите EXE с аргументом `--test-hotkey` и используйте **Ctrl+Alt+F12**. Откройте PowerShell в папке с EXE и выполните:

```powershell
Start-Process -FilePath .\layout-fixer.exe -ArgumentList '--test-hotkey'
```

Параметр `--lowercase` переводит весь результат в строчные буквы вместо сохранения регистра.

### Собственное сочетание клавиш

Укажите сочетание после `--hotkey`. Например, для **Ctrl+Alt+A**:

```powershell
Start-Process -FilePath .\layout-fixer.exe -ArgumentList '--hotkey', 'Ctrl+Alt+A'
```

Поддерживаются модификаторы `Ctrl`, `Alt`, `Shift`, `Win` и клавиши `A–Z`, `0–9`, `F1–F24`. Нужен хотя бы один модификатор. Порядок модификаторов не важен. Если сочетание уже занято Windows или другой программой, Layout Fixer покажет окно с ошибкой и не останется висеть в фоне.

Чтобы сочетание сохранилось после перезагрузки, создайте ярлык на EXE и добавьте аргументы в поле **Объект** после закрывающей кавычки:

```text
"C:\Tools\Layout Fixer\layout-fixer.exe" --hotkey Ctrl+Alt+A
```

Запустите этот ярлык для проверки. Для автозапуска переместите его в папку `shell:startup`. Выбранное сочетание отображается во всплывающей подсказке значка в трее.

### Автозапуск и удаление

Для portable-режима автозапуск включается вручную через ярлык в `shell:startup`. Для обычной установки распакуйте ZIP и запустите `install.cmd`: он создаст per-user установку, ярлык автозапуска и запись в списке установленных приложений. В меню трея доступны **Exit Layout Fixer** и **Uninstall Layout Fixer**; удаление также доступно через **Параметры → Приложения → Установленные приложения**. Установщик не требует администратора, службы или драйвера.

## Что лежит в релизе

- `layout-fixer.exe` — готовая переносимая программа. Это основной файл для скачивания.
- `layout-fixer-windows-x64.zip` — EXE, README, лицензия и per-user установщик/удалитель.
- `SHA256SUMS.txt` — контрольные суммы файлов сборки.
- `Source code (zip)` и `Source code (tar.gz)` — автоматически созданные GitHub архивы **исходного кода**, не установщики.

Код можно читать прямо на сайте: вкладка [Code](https://github.com/sosuchpak228/layout-fixer) и папка [src](https://github.com/sosuchpak228/layout-fixer/tree/main/src). Ядро преобразования — `src/lib.rs`, работа с выделением — `src/main.rs`, значок — `src/tray.rs`. Для просмотра кода конкретного выпуска откройте его тег на странице релиза.

## Ограничения

- Проверена работа с обычным полем `Edit` в Блокноте Windows 10 в обе стороны. Исправления для браузерных полей в этой версии экспериментальные: поиск Яндекса и ноды Magnific Canvas Space требуют проверки на реальных рабочих местах. Отдельный EXE для Windows 11 x64 не нужен, но реальный тест на Windows 11 ещё не пройден.
- Поля паролей, элементы только для чтения, неподдерживаемые редакторы, окна с повышенными правами и защищённый рабочий стол не обрабатываются. Нет запасного способа через буфер обмена.
- Выделение ограничено 16 384 единицами UTF-16. При смене активного окна или неоднозначном выделении программа ничего не заменит.

Для диагностики запустите вторую копию с `--test-hotkey --diagnostics` и проверьте **Ctrl+Alt+F12**. Эта опция выводит тип активного элемента, признаки редактирования и причину пропуска, но не записывает выделенный текст:

```powershell
Start-Process -FilePath .\layout-fixer.exe -ArgumentList '--test-hotkey', '--diagnostics' -RedirectStandardOutput "$env:TEMP\layout-fixer-test.out.log" -RedirectStandardError "$env:TEMP\layout-fixer-test.err.log"
```

После проверки закройте тестовую копию через значок в трее. Если сочетание не работает, [создайте issue](https://github.com/sosuchpak228/layout-fixer/issues) с версией Windows и приложения, шагами воспроизведения и, по желанию, этими диагностическими строками. **Не прикладывайте приватный текст, пароли и скриншоты с личными данными.**

## Сборка из исходников

Нужны Windows и Rust 1.98 с MSVC toolchain:

```powershell
cargo test --locked
cargo clippy --all-targets --locked -- -D warnings
cargo build --release --locked
```

Результат: `target/release/layout-fixer.exe`. Детали и план проверки — в [дизайн-заметках](docs/design.md). Лицензия — [MIT](LICENSE).
